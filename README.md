# E-portfolio de Kéheau Duroi

Site immersif multi-page pour un portfolio de Bloc 3 marketing à HELMo Campus Guillemins.

## Lancer le projet

```bash
npm install
npm run dev
```

Le site sera disponible sur `http://localhost:3000`.

## Structure

- `app/page.tsx` : grille de départ et présentation personnelle.
- `app/vision/page.tsx` : vision du marketing.
- `app/trajectoire/page.tsx` : stage Festina Lotus Belgium et ambition automobile de luxe.
- `app/conclusion/page.tsx` : conclusion réflexive.
- `data/content.ts` : contenu narratif centralisé.
- `components/` : composants réutilisables pour la navigation, les animations et les blocs visuels.
